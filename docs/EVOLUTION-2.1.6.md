# LUMORA Camera 2.1.6 / code 10 候选交付文档

## 1. 概览

2026-11-21 本地记录。**2.1.6 是未发布候选**（`versionName=2.1.6`、`versionCode=10`、`minSdk=29`）。最后核验的公开稳定版为 [v2.1.4 / code 8](https://github.com/yuchen0x1/LUMORA-Camera/releases/tag/v2.1.4)；本候选包含未发布的 2.1.5 / code 9 索引保全与更新缓存隔离修复。

## 2. 功能

- 取景器的「关闭」「三分网格」「黄金分割」使用稳定名称持久化，同步写入旧 Boolean 供旧格式兼容；兼容字段不能表达三分网格。设置页提供同样三种选择。
- 相机仍输出 JPEG，RAW 仅为能力提示，不生成 RAW/DNG。未对实体设备的厂商扩展作验收。

## 3. 修复

- 手动对焦请求失效近期 AF 成功缓存；应用 Camera2 选项前主动取消旧测光，避免继续依赖请求前的成功结果。
- 收紧发布元数据的数值类型和范围，新增 19 项离线 Python 回归并接入 CI。保留原有签名与资产校验，未替换更新信任根。
- 针对 Compose UI Test 1.7.6，将相关测试类限定为 `StandardTestDispatcher`，显式等待 IO 完成并检查主 Looper；不改生产调度。
- 复审发现并修复两项边界：进行中点按 AF 的迟到结果，以及其他设置写入覆盖未知网格值；另封堵了同步回滚抛错后迟到原请求成功的路径。最终对焦协调器回归覆盖这些状态。

## 4. 性能与架构

保留短期有效 AF 缓存，仅在请求影响其有效性时失效；没有测得拍摄/显影提速，也没有实体清晰度提升的证据。沿用单 app 模块、CameraX/Camera2、Compose 及现有照片处理管线；测试调度变更不改变生产线程模型。

## 5. 界面

## 9. 发布与安全

候选无标签、正式签名资产或 Release。最终 CI、签名包身份/公开摘要复核及从公开 v2.1.4 保留数据的签名覆盖升级均待完成；以[正式发布历史](../RELEASE_HISTORY.md)为准。

### 安全证据

本地未签名 Release APK 暴露面扫描为 **86/B**；含预期的未签名高风险项及既有 `allowBackup=true` 低风险项。评分是该中间产物的扫描输出，不是绝对安全等级。

### 威胁与影响

宽松的数值解析可能让发布端接受客户端拒绝的元数据，造成资产或更新不可用。未签名包没有正式签名身份、不得分发；`allowBackup` 的可导出范围取决于 Android 版本和设备备份策略。

### 修复与未改项

数值类型和范围校验在发布端失败即拒绝，并加入离线用例与 CI 步骤。本轮未新增秘密，未更换签名证书或信任根，也未更改备份策略。

### 验证

### 局限

静态扫描不能替代密码学验签、真实安装器或数据保留验收。早期未签名 APK 和历史公开版的结果均不能证明本候选的签名链、升级或备份策略安全。
